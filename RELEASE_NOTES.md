# Prompt Lite+ 1.2

Release date: 29 July 2026  
Build: 9706  
Complete executable version: 1.2.9706.24290  
Platform: 64-bit Windows  
Tested with Codex CLI: 0.146.0

## Highlights

- Lightweight VCL interface for Codex CLI `app-server`.
- Persistent project and conversation discovery from Codex CLI data.
- Independent multi-instance operation with one Codex CLI process per
  Prompt Lite+ instance.
- Conversation locking prevents the same thread from being opened in two
  Prompt Lite+ instances.
- Runtime model and reasoning selection.
- Direct approval, sandbox, review, and network-access controls.
- Tool, MCP, spawned-agent, activity, and file-change reporting.
- Diff history viewer and changed-file list.
- Bounded conversation rendering plus full transcript loading and search.
- Context-window, token-usage, task-duration, and account-limit indicators.
- Codex CLI detection, installation, version check, and update.
- Local staged Prompt Lite+ update support.
- Native Pin/Unpin support for conversations with compatible Codex CLI
  versions.
- Product and executable renamed to Prompt Lite+ / `PromptLitePlus`.
